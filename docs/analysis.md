# 分析报告（analysis.md）—— 考题四技术向

## 1. 摘要
二维素材→3D 的自动化难点在「几何正确性」与「贴图对齐」。本方案用**参数化模板/脚本承接几何、LLM 一句话 + 迭代修改驱动建模**，以 **CAD 机械壳体图纸 → 阶梯回转壳体 3D** 为主案例跑通完整流程（建模→材质→渲染→导出→Blender 查看）。

## 2. 核心流程
输入(二维图+一句话) → 参数化建模(回转体/盒体) → 贴图/材质 → 渲染(多视角) → 导出(.blend/.glb) → 查看(Blender/浏览器)。

## 3. 现状调研（LLM 辅助 Blender）
- BlenderGPT（2023）：单轮 NL→脚本，无排错；
- LL3M（arXiv:2508.08228）：多智能体+RAG+代码/渲染自检；
- CodeGen-3D 基准：通用 LLM 直接生成脚本失败率 21–92%，专用+迭代系统 3–4%。
结论：**不赌单次生成，模板兜底 + 反馈闭环**。

## 4. 难点与设计依据
| 维度 | 难点 | 对策 |
|---|---|---|
| 建模 | bpy.ops 依赖上下文；坐标/比例推理弱 | 数据层 API；尺寸参数化，不交给 LLM 心算 |
| 建模 | API 版本漂移（Blender 4.2→5.0 EEVEE 枚举变化） | 版本判断 resolve_engine；实测修复 |
| 贴图 | UV 与素材对齐、文字方向 | 分面映射 / 显式 UV 布局 |
| 材质/渲染 | 节点图复杂、无头无视觉反馈 | 封装 make_material；多视角出图人工/工具校验 |
